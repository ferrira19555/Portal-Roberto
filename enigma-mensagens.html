Como usar com segurança

Combine o código pessoalmente ou por um meio diferente daquele usado para enviar a mensagem.

Não envie o código junto com o bloco criptografado. Prefira um código longo e exclusivo; seis números não oferecem proteção suficiente contra tentativas automatizadas.

A ferramenta protege o conteúdo, mas não oculta quem enviou, quem recebeu, horários ou dados registrados pelo aplicativo usado para transportar o bloco.

Se o código for perdido, a mensagem não poderá ser recuperada. Use esta ferramenta como apoio e não como garantia de anonimato.
